Analyze unemployment trends during COVID-19 using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data Cleaning
- Data Visualization
- Trend Analysis

## Insights
- Unemployment increased during COVID-19.
- Different regions showed different unemployment rates.
- Trends changed over time.

## Conclusion
Successfully analyzed unemployment trends and visualized the impact of COVID-19 on unemployment rates.
